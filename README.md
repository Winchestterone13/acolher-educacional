# Acolher – Plataforma Educacional

Projeto acadêmico de acessibilidade, inclusão e saúde mental para estudantes, professores e famílias.

## Tecnologias
- HTML5, CSS3, JavaScript (vanilla)
- Python (servidor.py) para túnel local (opcional)

## Segurança
- Content‑Security‑Policy (CSP) restrita a recursos próprios.
- X‑Content‑Type‑Options (nosniff).
- Referrer‑Policy (no-referrer).

## Como rodar localmente
```bash
python3 servidor.py   # inicia o servidor HTTP + túnel público via localhost.run
```

## Deploy
1. Crie um repositório no GitHub.
2. Siga as instruções da seção **Próximos passos** para publicar com GitHub Pages.
